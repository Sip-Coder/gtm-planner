# GTM Planner

Mobile-first go-to-market planner (single static HTML). Open: https://sip-coder.github.io/gtm-planner/

Tabs: Pipeline · Contacts · Products · Plan · **Team** (company org — static, not saved in localStorage).

No personal or contact data is stored in this repo. Everything you enter is saved only in your browser (localStorage). Use Export JSON for backups.
